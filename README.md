# Diamond Supply Chain Portal

A small React portal app inspired by JVC Legal's "Protecting Your Diamond Supply Chain" guidance.

## Features

- Compliance-focused portal landing experience
- Resource cards for disclosure and supplier templates
- Supplier workflow overview
- Interactive self-audit checklist
- Leadership update section for next actions

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm run build
```
